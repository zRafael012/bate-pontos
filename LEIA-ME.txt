# Pacote de estabilidade - Bate Pontos

Arquivos incluídos:
- package.json
- app.json
- .gitignore
- .env.example
- src/services/notificacoesService.js

Depois de substituir/adicionar os arquivos, rode:

npm install
npx expo install expo-notifications expo-constants
npx expo-doctor
npx expo start -c

IMPORTANTE:
1. Remova o arquivo .env real do GitHub:
   git rm --cached .env
   git commit -m "remove env from repository"

2. Crie um .env local baseado no .env.example.

3. No App.js, adicione o import:
   import { configurarNotificacoes, cancelarNotificacoesJornada } from './src/services/notificacoesService';

4. Dentro do useEffect inicial do App.js, após iniciarApp();, chame:
   configurarNotificacoes();

5. Substitua COLE_AQUI_O_PROJECT_ID_DO_EAS no app.json pelo projectId real do EAS.
   Você pode obter/criar isso com:
   eas init
